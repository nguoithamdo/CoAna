Oligomer analysis for molecular dynamics

Which oligomers mattered, and why.

An aggregation trajectory holds thousands of short-lived clusters. CoAna follows every chain through every frame and tells you which assemblies went on to grow, which were dead ends, and whether a second protein joined the aggregate or only helped it start.

Demo data

One protein, three stories

The bulk curve says "it aggregated" or "it didn't". CoAna's lineage layer says how. These are the demo runs shipped with CoAna, produced with one command each.

A label on one visit in one run is a description, not evidence of catalysis. CoAna records the data for the real test: compare how often the guest's own assembly commits after a visit, for real guests against randomly chosen host chains treated as pseudo-guests, across replicates.

Incorporated
present when the assembly commits to growing, and still there at the end. A co-aggregate.
Catalytic
present before and at commitment, then leaves; the assembly carries on without it.
Passenger
joins an assembly that had already committed. Recruited by the aggregate.
Bystander
touches assemblies briefly; nothing grows, nothing commits.

Correctness

Numbers you can put in a paper

An analysis tool's errors end up in figures. CoAna is built to be checked.

bit-identical

Re-running 3.6.0 on a published campaign trajectory reproduces its 5001-frame contact cache exactly: every array and all metadata.

16 / 16

defects found in an independent audit are fixed, and each fix has a regression test shown to fail on the code before it.

10.3 %

of chain–chain contacts are lost when a trajectory has no periodic box. CoAna now refuses to run without one unless you say the system is not periodic.

259 tests

run on Linux and Windows, with and without MDAnalysis. CoAna itself needs only NumPy and SciPy and reads XTC, TRR, GRO and PDB directly.

Two stages

From trajectory to mechanism

Stage A reads the trajectory once and writes a compact contact cache: 6 MB for 5 µs of 60 chains, about 5 minutes on a desktop. Stage B answers questions from the cache in seconds to a minute, as often as you like.

Install

pip install coana

Stage A · contacts

coana precompute \
  --traj prod.xtc --topology prod.gro \
  --species aSyn:295x50,Ab40:92x10 \
  --contact-mode min_atom --cutoff 6.5 \
  --n-jobs 8 -o run.npz

Stage B · answers

coana lineage   run.npz -o lineage.csv
coana mechanism run.npz -o mechanism.csv
coana report    run.npz -o report.html

Author

Nguyen Truong Co

Truong Co Group. Since 2010 his work has asked what controls how proteins aggregate: the size of the critical nucleus, the role of crowders, surfaces and preformed templates, the kinetics and stability of fibrils. He has built lattice, Monte Carlo and coarse-grained models to answer it. CoAna is the analysis tool that grew out of that work.
